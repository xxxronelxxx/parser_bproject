❌ ПРОБЛЕМА: PyInstaller не включает модули автоматически
✅ РЕШЕНИЕ: Используем готовый spec файл с явными hiddenimports

📋 ШАГИ ДЛЯ СБОРКИ:

1️⃣ УБЕДИТЕСЬ ЧТО У ВАС ЕСТЬ ФАЙЛЫ:
   ✅ NovaskladParser.spec (готовый spec файл)
   ✅ parser-requests.py (основной парсер)
   ✅ build_with_spec.bat (скрипт сборки)

2️⃣ СПОСОБ 1: Автоматический (рекомендуется)
   - Двойной клик на build_with_spec.bat
   - Ждем завершения сборки
   - Получаем NovaskladParser.exe

3️⃣ СПОСОБ 2: Ручной через командную строку
   - Откройте cmd: Win + R → cmd → Enter
   - Перейдите в папку: cd /d D:\work\b-project.kz\git_parser
   - Выполните: pyinstaller NovaskladParser.spec

4️⃣ СПОСОБ 3: Если spec файл не работает
   - Удалите старый EXE: del NovaskladParser.exe
   - Удалите папки: rmdir /s /q build dist
   - Попробуйте: pyinstaller --onefile --name=NovaskladParser --collect-all=bs4 --collect-all=lxml --collect-all=pandas --collect-all=openpyxl --collect-all=rich --collect-all=requests parser-requests.py

🔍 ЧТО ДЕЛАЕТ SPEC ФАЙЛ:

✅ Явно указывает все необходимые модули:
   - bs4 (BeautifulSoup)
   - lxml (XML/HTML парсер)
   - pandas (работа с данными)
   - openpyxl (Excel файлы)
   - rich (красивый вывод)
   - requests (HTTP запросы)

✅ Включает все подмодули:
   - bs4.builder._lxml
   - lxml.etree, lxml.html
   - pandas._libs.tslibs
   - rich.console, rich.progress

🚨 ВОЗМОЖНЫЕ ПРОБЛЕМЫ И РЕШЕНИЯ:

❌ "ModuleNotFoundError: No module named 'bs4'"
✅ Решение: Используйте spec файл или --collect-all=bs4

❌ "Failed to execute script"
✅ Решение: Проверьте, что все зависимости установлены

❌ Большой размер EXE
✅ Решение: Это нормально, все модули включены

💡 АЛЬТЕРНАТИВНЫЕ КОМАНДЫ:

# Команда 1: С spec файлом
pyinstaller NovaskladParser.spec

# Команда 2: С collect-all
pyinstaller --onefile --name=NovaskladParser --collect-all=bs4 --collect-all=lxml --collect-all=pandas --collect-all=openpyxl --collect-all=rich --collect-all=requests parser-requests.py

# Команда 3: Простая (может не работать)
pyinstaller --onefile --name=NovaskladParser parser-requests.py

🎯 ПОРЯДОК ДЕЙСТВИЙ:

1. Убедитесь что у вас есть NovaskladParser.spec
2. Запустите build_with_spec.bat
3. Дождитесь завершения (5-10 минут)
4. Проверьте что NovaskladParser.exe работает
5. Если не работает - попробуйте команду 2

📞 ПОМОЩЬ: Если ничего не помогает:
- Проверьте что Python и pip установлены
- Установите зависимости: pip install -r requirements-requests.txt
- Перезапустите командную строку
- Попробуйте разные команды сборки

🎉 РЕЗУЛЬТАТ: Рабочий EXE файл со всеми модулями!
