# 📁 Использование файла cat.txt для изменения категории парсинга

## 🎯 Описание

Файл `cat.txt` позволяет легко изменить категорию товаров для парсинга без редактирования кода.

## 📋 Как использовать

### 1️⃣ Создание файла
Файл `cat.txt` создается автоматически при первом запуске парсера.

### 2️⃣ Изменение категории
Просто отредактируйте файл `cat.txt` и замените ссылку на нужную категорию:

**Примеры ссылок на разные категории:**
```
# Кухонные миксеры (по умолчанию)
https://novasklad.kz/catalog/kitchen-mixers/

# Блендеры
https://novasklad.kz/catalog/blenders/

# Кофемашины
https://novasklad.kz/catalog/coffee-machines/

# Пылесосы
https://novasklad.kz/catalog/vacuum-cleaners/

# Стиральные машины
https://novasklad.kz/catalog/washing-machines/

# Холодильники
https://novasklad.kz/catalog/refrigerators/

# Телевизоры
https://novasklad.kz/catalog/tvs/

# Смартфоны
https://novasklad.kz/catalog/smartphones/
```

### 3️⃣ Формат файла
- **Одна ссылка на строку**
- **Без лишних пробелов**
- **Обязательно с https://**
- **Должна заканчиваться на /**

## 🔧 Технические детали

### Автоматическое создание
Если файл `cat.txt` не существует, парсер:
1. Создает его автоматически
2. Записывает ссылку по умолчанию
3. Использует эту ссылку для парсинга

### Обработка ошибок
Если файл поврежден или пустой:
1. Парсер показывает предупреждение
2. Использует ссылку по умолчанию
3. Продолжает работу

### Логирование
Парсер показывает в консоли:
- ✅ Успешную загрузку ссылки
- ⚠️ Предупреждения о проблемах
- 📝 Создание файла по умолчанию

## 🚨 Важные моменты

### ✅ Что работает:
- Любые валидные ссылки на каталоги novasklad.kz
- Автоматическое создание файла
- Обработка ошибок

### ❌ Что НЕ работает:
- Ссылки на другие сайты
- Ссылки на отдельные товары
- Ссылки без https://
- Несколько ссылок в одном файле

## 🔍 Поиск ссылок на категории

### Способ 1: Через сайт
1. Зайдите на novasklad.kz
2. Перейдите в нужную категорию
3. Скопируйте URL из адресной строки

### Способ 2: Через карту сайта
1. Найдите ссылку "Карта сайта" внизу страницы
2. Выберите нужную категорию
3. Скопируйте ссылку

### Способ 3: Через поиск
1. Используйте поиск по сайту
2. Выберите категорию из результатов
3. Скопируйте ссылку

## 📊 Структура файла

```
cat.txt
├── Содержит только одну ссылку
├── Без лишних символов
├── С правильным форматом URL
└── Автоматически создается при необходимости
```

## 🎉 Результат

После изменения `cat.txt`:
- Парсер автоматически использует новую категорию
- Не нужно перекомпилировать EXE
- Не нужно редактировать код
- Быстрое переключение между категориями

## 💡 Советы

1. **Сохраняйте резервные копии** ссылок на часто используемые категории
2. **Проверяйте ссылки** перед парсингом
3. **Используйте правильный формат** URL
4. **Не удаляйте файл** - он создастся автоматически

## 🔧 Устранение проблем

### Проблема: Файл не создается
**Решение:** Проверьте права доступа к папке

### Проблема: Ссылка не работает
**Решение:** Проверьте правильность URL и доступность сайта

### Проблема: Парсер не видит изменения
**Решение:** Убедитесь что файл сохранен в кодировке UTF-8
