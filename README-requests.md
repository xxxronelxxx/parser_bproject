# 🚀 Парсер novasklad.kz (версия без браузера)

## 📋 Описание

Этот парсер работает **БЕЗ браузера** и WebDriver! Использует `requests` + `BeautifulSoup` для парсинга товаров с сайта novasklad.kz.

## ✨ Преимущества

- ✅ **Нет проблем с WebDriver** - работает без браузера
- ✅ **Быстрая работа** - не нужно ждать загрузки страниц
- ✅ **Надежность** - нет зависаний браузера
- ✅ **Простота** - минимум зависимостей
- ✅ **Автоматическая пагинация** - проходит все страницы

## 🛠️ Установка

### Способ 1: Автоматическая установка
```bash
python install-deps.py
```

### Способ 2: Ручная установка
```bash
pip install -r requirements-requests.txt
```

### Способ 3: Установка по одному
```bash
pip install requests beautifulsoup4 pandas openpyxl rich lxml
```

## 🚀 Запуск

```bash
python parser-requests.py
```

## 📊 Что парсит

- **Название товара** - полное название
- **Ссылка** - ссылка на страницу товара
- **Цена** - цена в тенге
- **Статус** - наличие на складе
- **Бренд** - производитель
- **Описание** - описание товара
- **Артикул** - артикул товара
- **Доп. артикул** - из названия в скобках

## 🔧 Настройка

### Изменение URL каталога
В файле `parser-requests.py` измените строку:
```python
self.catalog_url = "https://novasklad.kz/catalog/kitchen-mixers/"
```

### Изменение количества страниц
```python
max_pages = 50  # Максимальное количество страниц
```

### Изменение паузы между запросами
```python
time.sleep(1)  # Пауза в секундах между страницами
```

## 🎯 Особенности работы

### 1. **Автоматическое определение селекторов**
Парсер пробует разные CSS селекторы для поиска товаров:
- `.product`
- `.line .product`
- `.item`
- `.product-item`
- И другие...

### 2. **Умная пагинация**
Автоматически определяет формат пагинации:
- `?page=2`
- `page/2/`
- `?p=2`
- `?PAGEN_1=2`

### 3. **Обработка ошибок**
- Показывает подробную диагностику
- Продолжает работу при ошибках на отдельных страницах
- Сохраняет все найденные товары

### 4. **Статистика**
Показывает подробную статистику:
- Общее количество товаров
- Топ-5 брендов
- Распределение по статусам
- Количество товаров с ценами

## 🚨 Решение проблем

### Ошибка "ModuleNotFoundError"
```bash
pip install requests beautifulsoup4 pandas openpyxl rich lxml
```

### Ошибка "Permission denied"
```bash
# Запустите от имени администратора или используйте
pip install --user requests beautifulsoup4 pandas openpyxl rich lxml
```

### Медленная работа
Увеличьте паузу между запросами в коде:
```python
time.sleep(2)  # Вместо time.sleep(1)
```

### Товары не найдены
Проверьте, что URL каталога правильный и доступен в браузере.
